# SEO and author readability — 17 September 2026

Implemented consistent public-page titles, descriptions, canonical URLs and social previews. Article titles include the work's author; structured data links the author profile, publication and canonical article. The sitemap now includes the author index and privacy page. The new `/llms.txt` provides a public-content guide without exposing submissions or drafts.

Search pages retain `noindex, follow` and are crawlable so crawlers can see that directive. Private and development routes remain excluded in robots.txt. References: [Google's robots meta documentation](https://developers.google.com/search/docs/crawling-indexing/robots-meta-tag) and the [llms.txt proposal](https://llmstxt.org/). The latter is a discovery guide, not a search-ranking guarantee.

Migration 007 preserves any legacy content by moving that classification to Eseji, retaining category order and removing duplicates. Live inspection found zero affected revisions and submissions.

Author credits use heavier Source Sans, slightly larger text, and links to author profiles. Migration 006 uppercases stored author names and adds a database trigger for future inserts and name changes, including imports and accepted reader submissions. API normalization also returns uppercase names. Author IDs, slugs, account names and authored text stay intact.
